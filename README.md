Sistema de Gestão de Contactos em Python

 Descrição:
Sistema de gestão de contactos desenvolvido em Python utilizando uma interface de linha de comandos.

O projeto permite criar, listar, procurar, atualizar e eliminar contactos, armazenando os dados num ficheiro JSON.

 Funcionalidades

✔ Adicionar contacto

✔ Listar contactos

✔ Procurar contacto

✔ Atualizar contacto

✔ Eliminar contacto

✔ Guardar automaticamente em JSON

 Tecnologias:
- Python 3
- JSON
- Git
- GitHub

 Estrutura:
main.py
contactos.json
README.md
.gitignore

bash
python main.py
